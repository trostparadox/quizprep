# quizprep (public deploy)

The GitHub Pages deploy of **QuizPrep** — an adaptive weekly-quiz prep app for university courses. Live at https://trostparadox.github.io/quizprep.

This repo contains **only the built app** (index.html) and version.txt. It is a generated artifact — do not edit index.html here; it is built from a private source repo (app template + question banks) and copied in. The app is self-contained (no backend); it stores each student's progress locally and exports a JSON file the student uploads to Canvas.

Question-bank items are original works. No copyrighted course source texts are included.
